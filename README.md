 Bank Customer Churn Analysis

 
 📊 Project Overview
This project focuses on analyzing bank customer data to understand customer attrition patterns. By examining demographic factors, account information, and customer behavior, the goal is to identify key drivers behind why customers leave the bank, providing actionable insights for retention strategies.

 🛠️ Tools & Technologies Used
Microsoft Excel: Data cleaning, conditional formatting, formula calculations, and PivotTables.
Power BI: Interactive dashboard creation, custom KPI summary cards, regional mapping, and comparative visual charts.

📈 Key Insights & Features
Churn Overview: Tracked total customer volume versus active versus churned customers to calculate overall attrition rates.
Demographics & Attrition: Evaluated how factors like age, gender, income category, and education level impact customer retention.
Account Metrics: Analyzed transaction counts, credit limits, and relationship tenure to spot early warning signs of potential churn.
